# 3D资产库浏览器 - FBX Viewer (现代版)

一个基于Python的3D模型预览软件，支持FBX、OBJ等多种3D格式，可以快速浏览模型的网格和布线。采用现代化双栏布局，提供专业级资产管理体验。

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Python](https://img.shields.io/badge/python-3.7+-green.svg)

## ✨ 功能特性

- 🎯 **FBX文件预览**：原生支持FBX格式，改进的加载器带详细调试信息
- 📁 **现代化文件浏览器**：双栏布局，左侧目录树+右侧网格预览
- 💾 **多磁盘支持**：Windows下显示所有驱动器，Linux/Mac显示常用挂载点
- ⭐ **收藏夹功能**：快速访问常用的资产文件夹
- 🔍 **文件搜索**：顶部搜索栏快速查找文件
- 🖼️ **文件预览卡片**：图片显示缩略图，3D/其他文件显示彩色图标
- 🔄 **多种显示模式**：实体、线框、实体+线框
- 🖱️ **交互式3D视图**：鼠标旋转、缩放
- 📊 **实时模型信息**：顶点数、面数动态显示
- 🎨 **暗色主题界面**：专业优雅的深色UI

## 🖼️ 支持的文件格式

- ✅ FBX (.fbx)
- ✅ OBJ (.obj)
- ✅ Collada (.dae)
- ✅ 3DS (.3ds)
- ✅ STL (.stl)
- ✅ Blender (.blend)

- Python 3.7 或更高版本

## 🚀 安装步骤

### 1. 克隆或下载本项目

```bash
git clone <repository-url>
cd test_Desk_Claude
```

### 2. 安装Python依赖

```bash
pip install -r requirements.txt
```

**注意**：如果你在安装`pyassimp`时遇到问题，可能需要先安装Assimp库：

**Ubuntu/Debian:**
```bash
sudo apt-get install libassimp-dev
```

**macOS (使用Homebrew):**
```bash
brew install assimp
```

**Windows:**
通常`pip install pyassimp`即可，如果有问题可以尝试：
```bash
pip install pyassimp --no-cache-dir
```

### 3. 运行程序

```bash
python main.py
```

## 📖 使用说明

### 基本操作

1. **浏览文件**
   - 左上方"文件系统"面板：
     - 使用磁盘下拉框选择不同的驱动器/挂载点
     - 在文件树中导航到目标文件夹
     - 双击文件夹在右侧网格预览中打开

2. **文件预览**
   - 右上方"文件预览"面板显示当前目录的所有文件
   - 图片文件显示缩略图
   - 3D模型文件显示蓝色"3D"图标
   - 文件夹显示黄色文件夹图标
   - 双击文件加载到3D视图中

3. **加载3D模型**
   - 在文件预览网格中双击FBX或其他3D文件
   - 模型将在右下方"3D预览"窗口中显示
   - 模型信息（文件名、顶点数、面数）显示在3D窗口下方

4. **3D视图控制**
   - **旋转**：按住鼠标左键拖动
   - **缩放**：使用鼠标滚轮
   - **重置视图**：点击顶部工具栏的"重置视图"按钮

5. **显示模式**
   - 顶部工具栏可以切换显示模式：
     - ☑️ **实体**：显示模型表面（灰色材质）
     - ☑️ **线框**：显示模型布线（黑色线条）
     - 可以同时勾选查看实体+线框效果

6. **收藏夹功能**
   - 浏览到常用文件夹后，点击"+ 添加当前"将其加入收藏夹
   - 双击收藏夹中的文件夹快速跳转
   - 选中收藏项后点击"- 删除"可移除
   - 收藏夹数据保存在用户主目录的`.3d_asset_viewer_favorites.json`

7. **搜索功能**
   - 在顶部搜索框输入文件名关键词
   - 按回车或点击"搜索"按钮
   - 显示当前目录下匹配的文件列表

### FBX加载问题排查

如果FBX文件无法加载，请检查：

1. **PyAssimp是否正确安装**
   ```bash
   python -c "import pyassimp; print('OK')"
   ```

2. **查看控制台调试信息**
   - 启动程序时会显示PyAssimp加载状态
   - 加载模型时会显示详细的网格、顶点、面数信息
   - 如有错误会显示完整的异常堆栈

3. **FBX文件版本**
   - PyAssimp支持多数FBX版本，但某些特殊版本可能不兼容
   - 可以使用Blender重新导出为较新版本的FBX

4. **文件完整性**
   - 确认文件未损坏
   - 文件大小信息会在加载时显示

## 🐛 常见问题

### Q: 安装pyassimp失败
A: 确保系统已安装Assimp库（见上方安装步骤），或尝试：
```bash
pip install pyassimp --no-cache-dir
```

### Q: 打开软件显示黑屏
A: 检查显卡是否支持OpenGL 2.0+，尝试更新显卡驱动

### Q: 某些FBX文件无法加载
A: FBX格式有多个版本，如果遇到问题可以尝试：
- 使用Blender等软件重新导出为较新版本的FBX
- 转换为OBJ格式后加载

### Q: 模型显示不完整或变形
A: 这是归一化缩放的结果，软件会自动将模型缩放到合适大小以便预览

## 💡 技术栈

- **GUI框架**: PyQt5
- **3D渲染**: PyOpenGL
- **模型加载**: PyAssimp
- **数值计算**: NumPy

## 📝 开发说明

本项目采用模块化设计，各模块职责清晰：

- `model_loader.py`: 负责使用Assimp库加载各种3D模型格式
- `opengl_viewer.py`: 使用OpenGL实现3D渲染和交互
- `main_window.py`: PyQt5界面布局和用户交互逻辑
- `main.py`: 应用程序入口

如需扩展功能，可以：
- 添加更多显示选项（如材质、纹理支持）
- 实现更多相机控制（如平移、聚焦）
- 添加模型对比功能
- 支持导出截图
